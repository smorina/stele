STELE FOR WINDOWS
=================

1. Extract the complete Stele folder from the release ZIP.
2. Keep Stele.exe and the _internal folder together.
3. Double-click Stele.exe. Your normal browser opens the private local UI.

Stele is portable. It includes Python and every runtime prerequisite, installs
nothing, needs no administrator password, and works offline after download.

This hobby-project build is unsigned. Windows may show "Windows protected your
PC" the first time it runs. If you downloaded Stele from its official GitHub
release, choose More info, confirm the app name is Stele, and choose Run anyway.
Some managed computers do not permit unsigned applications.

Closing the browser does not stop Stele. Double-click Stele.exe again to reopen
the same private session. Use Quit Stele in the page when finished. Stele will
not quit while a build is queued or running.

Completed runs and diagnostics stay under:

    %USERPROFILE%\.stele
